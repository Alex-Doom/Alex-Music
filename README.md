# 🎵 AlexMusic

**AlexMusic** — это десктопный музыкальный плеер для Windows, написанный на **C++17** с использованием **Qt 6**. Приложение предназначено для воспроизведения локальных MP3-файлов с поддержкой метаданных, обложек альбомов, рейтингов, поиска, сортировки и интеграции с системными функциями Windows (панель задач, системный трей, уведомления).

Плеер создан с акцентом на **скорость работы**, **удобство навигации** и **автоматическую обработку повреждённых файлов**.

## ✨ Возможности

### Воспроизведение
- ▶️ Воспроизведение, пауза, перемотка треков
- ⏭️ Переход к следующему / предыдущему треку
- 🔁 Режим повтора одного трека
- 🔀 Случайный порядок воспроизведения (с историей навигации)
- 🔊 Регулировка громкости, кнопка Mute
- ⏱️ Правило 3 секунд: при нажатии «Предыдущий» трек перезапускается, если прошло более 3 секунд

### Управление библиотекой
- 📁 Сканирование папки с музыкой (включая подпапки)
- 🔍 Мгновенный поиск по всем колонкам с подсветкой совпадений
- ↕️ Сортировка кликом по заголовкам столбцов
- 🔄 Кнопка «Станд» для возврата к исходному / обратному порядку
- ⭐ Рейтинг треков (1–5 звёзд) прямо в таблице и в панели информации

### Метаданные и обложки
- 🏷️ Автоматическое чтение тегов **ID3v2** через библиотеку **TagLib**
- 🎨 Отображение обложек альбомов (из тега `APIC`)
- ⚡ Двухфазная загрузка: мгновенное отображение по имени файла → фоновая подгрузка реальных тегов
- 🛡️ Защита от «кракозябр» (некорректных кодировок кириллицы в тегах)

### Обработка ошибок
- ⚠️ Автоматическая валидация треков перед воспроизведением
- 🚫 Пропуск повреждённых / битых файлов (автоматически или с диалогом)
- 💾 Настройка «Всегда пропускать повреждённые треки»

### Интеграция с Windows
- 🖼️ **Thumbnail Toolbar** в панели задач — 5 кнопок: Повтор, Предыдущий, Play/Pause, Следующий, Случайный порядок
- 📢 Кастомные **всплывающие уведомления** «Сейчас играет» с обложкой трека
- 🎯 Иконка в **системном трее** с контекстным меню
- 🔌 Автоматическое переподключение при смене аудиоустройства по умолчанию

### Интерфейс
- 📊 Таблица треков с колонками: Название, Исполнитель, Жанр, Альбом, Рейтинг, Год, Длительность, Размер, Путь
- 🎨 Градиентный фон окна, стилизованные кнопки и слайдеры
- 📋 Меню: Файл, Настройки, Справка
- ⌨️ Полная поддержка горячих клавиш
- 💾 Сохранение геометрии окна, громкости и настроек между запусками

## 📦 Зависимости

### Обязательные

- **Qt 6.9+** (модули: `Core`, `Widgets`, `Multimedia`, `Concurrent`)
  - Скачать: [https://www.qt.io/download](https://www.qt.io/download)
- **TagLib** (библиотека для работы с аудио-тегами)
  - Скачать: [https://taglib.org/](https://taglib.org/)
  - Для Windows (MinGW): собрать из исходников или использовать [vcpkg](https://vcpkg.io/)
- **CMake 3.16+**
  - Входит в состав Qt Creator, либо скачать отдельно: [https://cmake.org/download/](https://cmake.org/download/)
- **Компилятор**
  - Минимально поддерживаемый: **MinGW 11+** (входит в Qt) или **MSVC 2019+**

### Установка TagLib (Windows + MinGW)

```bash
# Вариант 1: через vcpkg
vcpkg install taglib:x64-mingw-dynamic

# Вариант 2: сборка из исходников
git clone https://github.com/taglib/taglib.git
cd taglib
mkdir build && cd build
cmake -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release ..
mingw32-make -j8
mingw32-make install
```

## 🔨 Сборка проекта

### Через Qt Creator (рекомендуется)

1. Откройте **Qt Creator**
2. **Файл → Открыть файл или проект** → выберите `CMakeLists.txt`
3. Выберите комплект сборки (например, **Desktop Qt 6.9.3 MinGW 64-bit**)
4. Нажмите **Собрать** (🔨) или `Ctrl+B`
5. Запустите приложение (▶️) или `Ctrl+R`

### Через командную строку

```bash
mkdir build && cd build

cmake .. -G "MinGW Makefiles" \
  -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_PREFIX_PATH="C:/Qt/6.9.3/mingw_64" \
  -DTAGLIB_INCLUDE_DIRS="C:/taglib/include" \
  -DTAGLIB_LIBRARIES="C:/taglib/lib/libtag.dll.a"

mingw32-make -j8
```

### Проверка сборки

После успешной сборки в папке `build/` появится исполняемый файл `AlexMusic.exe`. Для запуска убедитесь, что рядом находятся все необходимые DLL (используйте `windeployqt`):

```bash
windeployqt AlexMusic.exe
```

## ⚠️ Обработка повреждённых треков

При обнаружении битого трека приложение:

1. **Проверяет файл** на:
   - Существование
   - Нулевой размер
   - Корректное расширение `.mp3`
   - Валидную длительность (> 1 секунды)

2. **Если включён автоспуск** (настройка «Всегда пропускать»):
   - Трек пропускается автоматически
   - Поиск следующего валидного трека в заданном направлении

3. **Если автоспуск выключен**:
   - Показывается диалог с информацией об ошибке
   - Пользователь выбирает: «Пропустить и продолжить» или «Остановить»
   - Опционально: галочка «Всегда пропускать» для включения автоспуска

## 🏷️ Работа с метаданными

### Двухфазная загрузка

Для обеспечения **мгновенного** отображения таблицы при открытии папки используется двухфазный подход:

```
Фаза 1 (мгновенно):
  ├── Сканирование файловой системы (QDirIterator)
  ├── Парсинг имени файла ("Исполнитель - Название.mp3")
  └── Отображение таблицы с базовыми данными

Фаза 2 (в фоне):
  ├── Чтение реальных тегов через TagLib
  ├── Обновление данных в плейлисте
  └── Обновление ячеек таблицы
```

### Поддерживаемые теги

| Тег | Поле | Фрейм ID3v2 |
|---|---|---|
| Название трека | `title` | `TIT2` |
| Исполнитель | `artist` | `TPE1` |
| Альбом | `album` | `TALB` |
| Жанр | `genre` | `TCON` |
| Год | `year` | `TYER` / `TDRC` |
| Номер трека | `trackNumber` | `TRCK` |
| Обложка | `coverImage` | `APIC` |
| Рейтинг | `rating` | `POPM` |

### Защита от некорректных кодировок

Приложение автоматически обнаруживает и исправляет «кракозябры» — ситуацию, когда кириллические теги записаны в кодировке Windows-1251, но помечены как Latin-1. Алгоритм:

1. Декодировать строку как UTF-8
2. Подсчитать количество символов диапазона `U+00C0–U+00FF` (Latin-1 Supplement)
3. Если таких символов > 1 → передекодировать из Windows-1251
4. Проверить наличие кириллицы (`U+0400–U+04FF`) в результате

## ⭐ Рейтинги

Рейтинг треков хранится в двух местах:

1. **В файле рейтингов** (`ratings.txt` рядом с исполняемым файлом) — формат: `путь|рейтинг`
2. **В теге POPM** MP3-файла (при сохранении через TagLib) — значение 0–255

Рейтинг можно установить:
- Кликом по звёздам в **левой панели** (для текущего трека)
- Кликом по звёздам в **таблице** (для любого трека)

Диапазон: **1–5 звёзд**. Повторный клик на ту же звезду не сбрасывает рейтинг (для сброса нужно использовать значение 0).

## 🚧 Известные ограничения

| Ограничение | Причина | Статус |
|---|---|---|
| Поддерживаются только MP3 | Использование `TagLib::MPEG::File` | В планах: FLAC, OGG, WAV |
| Одна папка за раз | Архитектура `scanFolder()` | В планах: мультипапки |
| Нет плейлистов (M3U) | Не реализовано | В планах |
| Рейтинги в `.txt` рядом с `.exe` | Нет записи в `Program Files` | В планах: `QStandardPaths` |
| `QTableWidget` вместо модели | Медленно на 10 000+ треков | В планах: `QTableView` + модель |
| Нет эквалайзера | Ограничение `QAudioOutput` | В планах |
| Нет кроссфейда | Не реализовано | В планах |

## ❓ Часто задаваемые вопросы

**Вопрос: Приложение не находит иконку / обложку по умолчанию?**
Убедитесь, что файлы `app_icon.ico` и `default.jpg` находятся рядом с исполняемым файлом или в папке `icons/` / `images/`.

**Вопрос: Треки не воспроизводятся?**
Проверьте, что файлы имеют расширение `.mp3`, не повреждены и их размер больше 0 байт. Приложение автоматически пропустит невалидные файлы.

**Вопрос: Теги отображаются «кракозябрами»?**
Приложение автоматически пытается исправить кодировку. Если проблема сохраняется, пересохраните теги в любом редакторе тегов (например, [Mp3tag](https://www.mp3tag.de/)) в кодировке **UTF-8**.

**Вопрос: Как изменить папку с музыкой по умолчанию?**
В данный момент папка `C:\Users\User\Music` зашита в код. Для изменения отредактируйте переменную `defaultFolder` в конструкторе `MainWindow`. В планах — сохранение последней использованной папки в настройках.
